# Math Module

This module provides basic mathematical calculation functions for use in both Node.js and React environments.

## Functions

### `calculateTwoNumbers(a, b)`
Calculates the sum of two numbers.

**Parameters:**
- `a` (number): The first number.
- `b` (number): The second number.

**Returns:**
- `number`: The sum of `a` and `b`.

## Example Usage

```js
import { calculateTwoNumbers } from './math.js';

const result = calculateTwoNumbers(3, 5);
console.log(result); // 8
```
