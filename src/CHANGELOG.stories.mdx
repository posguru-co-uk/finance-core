# @posguru/finance-core

A universal JavaScript library for finance-related math functions. Usable in both Node.js (Express) and React applications.

## Installation

```sh
npm install @posguru/finance-core
```

## Usage

```js
import { calculateTwoNumbers } from '@posguru/finance-core';

const result = calculateTwoNumbers(2, 3);
console.log(result); // 5
```

## Modules
- `math.js`: Basic math functions (addition, etc.)
